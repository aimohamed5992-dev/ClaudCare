# ClaudCare – واجهة نظام إدارة المستشفيات

واجهة **React 19 + Vite + React Router**، عربية RTL، خلفية بيضاء في كل الشاشات، متصلة بـ API الباك اند (`../backend`).

## الاتصال بالخادم
- العنوان: `VITE_API_URL` (الافتراضي `http://localhost:5080`). شغّل الـ API وMySQL أولًا (انظر `../README.md`).
- **الدخول حقيقي:** `src/api/` عميل `fetch` بتجديد تلقائي للرمز عند 401 (مرة واحدة حتى مع طلبات متزامنة) وأخطاء موحدة `ApiError`؛ الطاقم يمر برمز OTP؛ استعادة كلمة المرور على الخادم (حساب ← رمز ← كلمة جديدة). **دور الحساب من الخادم**، فاختيار الدور اليدوي أُزيل.
- **البيانات:** `src/api/hydrate.js` يملأ مصفوفات `src/data/*` التي تقرؤها صفحات كل دور من الـ API عند الدخول وعند كل تنقل (وكل دقيقة)، عبر `src/api/mappers.js` الذي يحوّل ردود الخادم إلى شكل الصفوف نفسه؛ فتعمل الصفحات دون تغيير ولا يُعاد بناء الصفحة إلا إن تغيّرت البيانات. الإشعارات حيّة (تحديث كل 30 ثانية) مع تعليم مقروء وحذف على الخادم.
- **مقروء من الخادم:** المختبر · الأشعة · الصيدلية (وصفات، مخزون، أوامر شراء، مبيعات) · الطبيب (مواعيد، مرضى) · الاستقبال (طابور، حجوزات، فواتير) · المالية (فواتير، مصروفات) · الموارد البشرية (موظفون، إجازات) · التأمين (موافقات، مطالبات) · الطوارئ · التنويم (طلبات) · العمليات · المريض (مواعيد، فواتير) · الإشعارات.
- **ما زال تجريبيًا في الواجهة:** لوحات الإدارة (مدير النظام/المستشفى/الفرع) والإحصاءات التجميعية، الرسوم البيانية، شاشات التمريض، أسرّة التنويم، وإجراءات الكتابة داخل الصفحات (صرف وصفة، إدخال نتيجة، اعتماد…) فهي تتغير في الذاكرة فقط؛ نقاط نهايتها جاهزة في الـ API (انظر `../backend/docs/API-OPERATIONS.md`).
- **تحقق حي:** `node scripts/e2e-live.mjs` يدخل بالأدوار الستة عشر ويجلب بياناتها ويختبر تجديد الرمز والخروج.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # بناء الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
npm run lint
```

- الدخول بحسابات التجربة (`../README.md`): مثل `DR-1042` أو `pharmacy@claudcare.test` وكلمة المرور `Demo@1234` ورمز التحقق `123456`.
- صفحة مراجعة المكونات `/ui` متاحة في وضع التطوير فقط.

## الأدوار الستة عشر

المدير `admin` · المستشفى `hospital` · الفرع `branch` · المختبر `lab` · الأشعة `radiology` · الصيدلية `pharmacy` · التأمين `insurance` ·
الطبيب `doctor` · الممرض/ة `nurse` · الاستقبال `reception` · المحاسب `finance` · الموارد البشرية `hr` · الطوارئ `emergency` · الإدخال `admissions` · العمليات `surgery` · المريض `patient`

المسار العام: `/:role/<page>` مثل `/doctor/patients`. وفي كل دور: `/notifications` و`/profile` و`/settings`.
صفحات فرعية خارج القائمة الجانبية: `/doctor/consultation` · `/lab/entry` · `/radiology/viewer` · `/pharmacy/dispense` · `/insurance/review` · `/finance/collect` · `/admissions/admit`.

## بنية المشروع

```
src/
  styles/            tokens.css (الألوان والمسافات) · base.css
  components/
    ui/              مكونات أساسية: Button, Input, Card, Badge, Modal, DataTable, Tabs...
    patterns/        قوالب: DashboardTemplate, ListPage, SettingsTemplate, LabReport, StudyGrid, Messenger
    layout/          AppShell, Sidebar, Topbar, GlobalSearch, حراس المسارات
  context/ hooks/    الجلسة (AuthProvider) والإشعارات
  data/              roles.js (الأدوار والقوائم) + بيانات تجريبية لكل دور
  pages/
    auth/            الدخول · نسيت كلمة المرور · إعادة التعيين
    <role>/          <Role>Pages.jsx (الشاشات) + screens.jsx (خريطة المسارات)
    common/          الإشعارات · الملف الشخصي · الإعدادات
  utils/             assets.js · validators.js · cx.js
public/assets/       الصور (WebP مضغوطة، ~2.5MB)
```

## إضافة صفحة جديدة لدور

1. أضف عنصرًا في `nav` للدور داخل `src/data/roles.js` (المسار والاسم والأيقونة).
2. أنشئ الشاشة في `src/pages/<role>/<Role>Pages.jsx` باستخدام القوالب:
   - `DashboardTemplate` للوحات · `ListPage` للقوائم مع تفاصيل ونموذج إضافة · `SettingsTemplate` للإعدادات.
3. سجّلها في `src/pages/<role>/screens.jsx` بالمفتاح نفسه: `mypage: <MyPage />`.
   للصفحة الفرعية (غير الظاهرة في القائمة) أضف عنوانها في `SUBPAGE_TITLES` داخل `roles.js`.

كل دور يُحمَّل في حزمة مستقلة (`React.lazy`) عند أول دخول له.

## الصور

تُكتب المسارات في الكود بامتدادات `png/jpg` ويحوّلها `asset()` في `utils/assets.js` إلى `.webp` تلقائيًا.
المصادر الأصلية غير المضغوطة في `../design/assets`.
